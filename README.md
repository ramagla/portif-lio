# Portfólio — Rafael Almeida

Cartão de visita digital de Rafael Almeida, profissional de gestão de projetos de TI e desenvolvimento full stack.

## Destaques

- Página única, direta e responsiva.
- Posicionamento profissional alinhado entre gestão, dados e tecnologia.
- Projetos selecionados: Portal de Gestão, SIB, Romeu Beauty e Duda 16.
- Contatos para LinkedIn, GitHub e e-mail.

## Rodar localmente

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.

## Validar a versão de produção

```bash
npm run build
```

## Stack

- React
- TypeScript
- CSS
- React Icons
- Vercel Analytics
